📜 Análise do default.yaml
yaml
apiVersion: 1

providers:
  - name: 'CPD Dashboards'        # Nome interno do provider (só para log)
    orgId: 1                       # Organização padrão do Grafana
    folder: 'CPD'                  # Pasta onde os dashboards aparecem na UI
    type: file                     # Tipo: lê de arquivos JSON no disco
    disableDeletion: false         # Permite deletar o dashboard pela UI (mas o JSON o recria)
    updateIntervalSeconds: 30      # A cada 30s, o Grafana relê a pasta
    allowUiUpdates: false          # UI NÃO pode sobrescrever o JSON (IaC puro)
    options:
      path: /var/lib/grafana/dashboards   # Caminho DENTRO do container
      foldersFromFilesStructure: false    # Não cria subpastas baseadas em pastas do disco
Por que cada linha importa:
Linha	O que faz	Impacto para o 3D
folder: 'CPD'	Agrupa os dashboards na pasta "CPD" da UI	O cpd-3d.json vai aparecer junto com o cpd-dashboard.json
updateIntervalSeconds: 30	Relê o disco a cada 30s	Quando você criar o cpd-3d.json, ele aparecerá em até 30s (sem restart)
allowUiUpdates: false	UI não sobrescreve o JSON	Se você editar o 3D na UI, será ignorado no próximo restart. O JSON é a fonte da verdade
path: /var/lib/grafana/dashboards	Pasta DENTRO do container	É mapeada para ./grafana/dashboards no seu Mac via docker-compose.yml
🎯 Como o 3D vai se encaixar
Quando você criar o arquivo grafana/dashboards/cpd-3d.json:

O Grafana vai relê-lo em até 30s (por causa do updateIntervalSeconds).

O dashboard CPD 3D vai aparecer na pasta CPD do menu lateral.

Como allowUiUpdates: false, qualquer edição na UI será descartada. Só o JSON manda.

Se você deletar o dashboard pela UI, ele volta em 30s (porque o JSON ainda está no disco).

Isso é o IaC puro funcionando. O arquivo JSON é o "contrato" do dashboard.

            led.position.set(-1.2, 1 + i, 1.05);
            scene.add(led);
        }

        function animate() {
            requestAnimationFrame(animate);
            controls.update();
            renderer.render(scene, camera);
        }
        animate();

        window.addEventListener('resize', () => {
            camera.aspect = window.innerWidth / window.innerHeight;
            camera.updateProjectionMatrix();
            renderer.setSize(window.innerWidth, window.innerHeight);
        });
    </script>

🎯 Por que o projeto original não tem .html?
O projeto original usa uma arquitetura diferente do que estamos construindo. Ele não roda em um iframe isolado — ele roda direto no Grafana, como um painel nativo (Business Text). Nesse modelo:

O noc.js é carregado pelo próprio painel do Grafana (via import('/public/noc/noc.js')).

O HTML (a estrutura da página) já existe — é o próprio painel do Grafana que fornece o <div> onde o 3D é renderizado.

O CSS é injetado dinamicamente pelo noc.js (não há um <link rel="stylesheet">).

O cena3d.js é importado pelo noc.js (não há um <script> no HTML).

Em resumo: o projeto original não tem um .html porque ele não é uma página isolada. Ele é um "módulo" que se pluga no Grafana, e o Grafana já fornece a página (HTML) onde ele vai morar.

🛠️ Por que nós estamos criando um .html?
Nós tentamos fazer o mesmo (painel Business Text + import('/public/noc/noc.js')), mas esbarramos em vários bloqueios:

Problema	O que aconteceu
CSP (Content Security Policy)	O Grafana bloqueia a execução de import() de scripts externos dentro de painéis, por segurança.
Sanitização do HTML	O painel Business Text remove <script> tags e <div> que não são "seguros".
Dependência do noc.js	O noc.js original depende do @grafana/runtime e da API do Zabbix, que não existem no nosso contexto (mockamos os dados).
Tamanho do painel	O Business Text não respeita o height:600px de um <div> interno (o painel corta o conteúdo).
A solução: em vez de tentar "plugar" o cena3d.js no Grafana (que tem regras rígidas), criamos uma página HTML independente (noc3d.html) que carrega o cena3d.js e roda dentro de um iframe no painel do Grafana. O iframe é uma "janela isolada" que ignora as regras do CSP do Grafana (com allow_embedding = true).

📊 Comparação: projeto original vs. nosso projeto
Aspecto	Projeto Original	Nosso Projeto (Fatia 6)
Como o 3D é carregado	import('/public/noc/noc.js') dentro do painel Business Text	<iframe src="/public/grafana-custom/noc/noc3d.html">
HTML	Fornecido pelo Grafana (painel)	Fornecido por um arquivo noc3d.html
CSS	Injetado pelo noc.js	<link rel="stylesheet" href="estilo.css">
Dados	Vêm do Zabbix via dados.js	Mockados no noc3d.html (por enquanto)
Dependências	@grafana/runtime, Zabbix API	Three.js (local) + cena3d.js
Vantagem	Integração nativa com o Grafana	Isolamento (sem CSP, sem sanitização)
Desvantagem	Bloqueado por CSP, sanitização, etc.	Precisa de allow_embedding = true

O noc3d.html é a "cola" que faltava. Ele permite que o cena3d.js (o coração do 3D) rode sem as restrições do Grafana. É um padrão muito comum em dashboards profissionais: iframes para componentes complexos (3D, mapas, vídeos) e painéis nativos para dados simples (gráficos, tabelas).

      g.position.set(ar.position.x + g.userData.dx, 2.3 * (1 - q * q), ar.position.z + 0.25);

      pz.material.opacity = suave(pz.material.opacity, alvo.energiaOk ? 0.75 * Math.sin(Math.PI * q) : 0, 6);
      pz.visible = pz.material.opacity > 0.01;
    }

    giroflex.visible = !!alvo.giroflex;

    giroflex.rotation.y += dt * (grave ? 5 : 2.5);

    matGiroflex.emissiveIntensity = alvo.giroflex ? 1.5 + Math.sin(t * (grave ? 10 : 5)) : 0;

    matLedSensor.emissiveIntensity = !alvo.online ? 0
      : alvo.alertaSensor ? (Math.floor(t * 8) % 2 ? 1.8 : 0.2) : 1.4;

    controles.update();
    renderer.render(cena, camera);
  }

  function redimensionar() {
    const w = Math.max(200, caixa.clientWidth);
    const h = Math.max(200, caixa.clientHeight);
    renderer.setSize(w, h);
    const aspecto = w / h;
    const alturaVista = 6.4;
    camera.top = alturaVista / 2;
    camera.bottom = -alturaVista / 2;
    camera.left = (-alturaVista * aspecto) / 2;
    camera.right = (alturaVista * aspecto) / 2;
    VISTA.zoom = aspecto < 1.5 ? 0.85 * (aspecto / 1.5) + 0.15 : 1;
    if (!selecionado) camera.zoom = VISTA.zoom;
    camera.updateProjectionMatrix();
  }

  let selecionado = null;

  function destruir() {
    vida.viva = false;
    cancelAnimationFrame(quadro);
    observador.disconnect();
    controles.dispose();
    cena.traverse((o) => {
      o.geometry?.dispose?.();
      if (o.material) (Array.isArray(o.material) ? o.material : [o.material]).forEach((m) => {
        m.map?.dispose(); m.dispose();
      });
    });
    renderer.dispose();
  }

  const observador = new ResizeObserver(redimensionar);
  observador.observe(caixa);
  redimensionar();
  animar();

  return Object.assign(vida, { atualizar, destruir });
}

function texturaCanvas(w, h, desenhar) {
  const canvas = document.createElement('canvas');
  canvas.width = w; canvas.height = h;
  desenhar(canvas.getContext('2d'), w, h);
  const t = new THREE.CanvasTexture(canvas);
  t.colorSpace = THREE.SRGBColorSpace;
  return t;
}

function pintarCanvas(textura, desenhar) {
  const c = textura.image.getContext('2d');
  c.clearRect(0, 0, textura.image.width, textura.image.height);
  desenhar(c, textura.image.width, textura.image.height);
  textura.needsUpdate = true;
}

function criarVisor(w, h) {
  const textura = texturaCanvas(w, h, (c) => {
    c.fillStyle = '#0e1114'; c.fillRect(0, 0, w, h);
  });
  let anterior = '';
  return {
    textura,
    escrever([l1, l2, cor], grande = false) {
      const chave = l1 + l2 + cor;
      if (chave === anterior) return;
      anterior = chave;
      pintarCanvas(textura, (c) => {
        c.fillStyle = '#0e1114'; c.fillRect(0, 0, w, h);
        c.fillStyle = cor; c.textBaseline = 'middle';
        c.font = `${grande ? 'bold ' : ''}${Math.round(h * (grande ? 0.42 : 0.32))}px Consolas, monospace`;
        c.fillText(l1, 10, h * (grande ? 0.34 : 0.32));
        c.font = `${Math.round(h * (grande ? 0.24 : 0.32))}px Consolas, monospace`;
        c.fillText(l2, 10, h * (grande ? 0.76 : 0.72));
      });
    },
  };
