🛑 O erro continua por causa do - no comando
O erro SyntaxError: unterminated statement significa que o Zabbix está usando um interpretador de JavaScript para tentar ler o comando (ele acha que é um código JS). Isso acontece porque o Zabbix não permite certos caracteres na sintaxe do script.

O problema é o hífen (-) seguido de letras (como em -h, -t, -C). O parser do Zabbix entende isso como operador de subtração ou nome de variável, e quebra.

Para contornar isso de forma definitiva no Zabbix, precisamos mudar a abordagem: em vez de usar o tipo Script com mosquitto_sub, vamos usar o tipo External check (Verificação Externa). Ele executa um script do sistema operacional, sem o parser de JavaScript atrapalhar.

Passo 1 — Criar o script no container do Zabbix
O Zabbix tem uma pasta específica para scripts externos (/usr/lib/zabbix/externalscripts). Vamos criar um script lá dentro.

Rode este comando no seu terminal (Mac):

bash

python
import os
import requests
import json
from dotenv import load_dotenv

# Carrega as variáveis do .env
load_dotenv()

ZABBIX_URL = os.getenv("ZABBIX_URL")
ZABBIX_USER = os.getenv("ZABBIX_USER")
ZABBIX_PASSWORD = os.getenv("ZABBIX_PASSWORD")
API_URL = f"{ZABBIX_URL}/api_jsonrpc.php"

def zabbix_api_call(method, params, auth_token=None):
    headers = {"Content-Type": "application/json-rpc"}
    payload = {
        "jsonrpc": "2.0",
        "method": method,
        "params": params,
        "id": 1
    }
    if auth_token:
        payload["auth"] = auth_token

    response = requests.post(API_URL, headers=headers, json=payload)
    response.raise_for_status()
    result = response.json()
    
    if "error" in result:
        raise Exception(f"Erro na API do Zabbix: {result['error']}")
    return result["result"]

def main():
    print("1. Autenticando na API do Zabbix...")
    auth = zabbix_api_call("user.login", {"username": ZABBIX_USER, "password": ZABBIX_PASSWORD})
    print("   Login OK!")

    print("2. Buscando o Host 'esp32-cpd'...")
    hosts = zabbix_api_call("host.get", {"filter": {"host": ["esp32-cpd"]}}, auth)
    if not hosts:
        print("   ERRO: Host 'esp32-cpd' não encontrado. Você criou ele na interface?")
        return
    host_id = hosts[0]["hostid"]
    print(f"   Host encontrado. ID: {host_id}")

    print("3. Buscando o Item Mestre 'MQTT Status'...")
    master_items = zabbix_api_call("item.get", {
        "hostids": host_id,
        "filter": {"key_": ["mqtt_status.sh"]}
    }, auth)
    if not master_items:
        print("   ERRO: Item Mestre 'mqtt_status.sh' não encontrado.")
        return
    master_item_id = master_items[0]["itemid"]
    print(f"   Item Mestre encontrado. ID: {master_item_id}")

    # Lista com os 7 itens a serem criados
    itens_dependentes = [
        {"name": "Umidade",      "key": "esp32.umid",      "type": 0, "units": "%", "jsonpath": "$.umid_pct"},   # type 0 = float
        {"name": "Porta Aberta", "key": "esp32.porta",     "type": 4, "units": "",  "jsonpath": "$.porta"},      # type 4 = text
        {"name": "Modo",         "key": "esp32.modo",      "type": 4, "units": "",  "jsonpath": "$.modo"},
        {"name": "Estado",       "key": "esp32.estado",    "type": 4, "units": "",  "jsonpath": "$.estado"},
        {"name": "Distância",    "key": "esp32.distancia", "type": 0, "units": "cm","jsonpath": "$.dist_cm"},
        {"name": "Invasões",     "key": "esp32.invasoes",  "type": 3, "units": "",  "jsonpath": "$.invasoes"},   # type 3 = unsigned
        {"name": "Ambiente",     "key": "esp32.ambiente",  "type": 4, "units": "",  "jsonpath": "$.ambiente"},
    ]

    print("\n4. Criando/Atualizando os 7 itens dependentes...")
    for item in itens_dependentes:
        print(f"   -> Criando '{item['name']}' (JSONPath: {item['jsonpath']})...")
        
        payload_item = {
            "hostid": host_id,
            "name": item["name"],
            "key_": item["key"],
            "type": 18,  # Tipo 18 = Dependent Item
            "value_type": item["type"],
            "units": item["units"],
            "master_itemid": master_item_id,
            "preprocessing": [
                {
                    "type": 12,  # Tipo 12 = JSONPath
                    "params": item["jsonpath"],
                    "error_handler": 0,
                    "error_handler_params": ""
                }
            ],
            "delay": "0" # Herda do master
        }

        # Tenta criar. Se já existir (erro), tenta atualizar
        try:
            zabbix_api_call("item.create", payload_item, auth)
            print("      Criado com sucesso!")
        except Exception as e:
            if "already exists" in str(e) or "SQ" in str(e):
                print("      Item já existe. Atualizando...")
                # Busca o ID do item existente e atualiza
                existing = zabbix_api_call("item.get", {"hostids": host_id, "filter": {"key_": item["key"]}}, auth)
                if existing:
                    payload_item["itemid"] = existing[0]["itemid"]
                    zabbix_api_call("item.update", payload_item, auth)
                    print("      Atualizado!")
            else:
                print(f"      ERRO: {e}")

    print("\n5. Finalizando...")
    zabbix_api_call("user.logout", {}, auth)
    print("Tudo pronto! Verifique a interface em Monitoring -> Latest data.")

if __name__ == "__main__":
    main()

🎯 Vamos para a Fatia 3: Gatilhos e Telegram
Agora que temos os dados estruturados, vamos fazer o Zabbix pensar. Ele vai olhar para esses valores e, se algo sair do normal, vai nos avisar.

Passo 3.1 — Criar o Bot no Telegram (2 minutos)
Para o Zabbix enviar mensagens, precisamos de um "bot" no Telegram.

No seu celular (ou no Telegram Web), procure o contato @BotFather.

Envie a mensagem: /newbot

Ele vai pedir um nome para o bot (ex: Monitor CPD).

Ele vai pedir um username (precisa terminar com "bot", ex: monitor_cpd_cristiano_bot).

Ele vai te dar um Token de Acesso (parece uma string longa tipo 123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ).
Anote esse token!

Passo 3.2 — Descobrir o seu Chat ID
O bot precisa saber para quem enviar a mensagem (no caso, você).

Mande uma mensagem qualquer (ex: "Oi") para o seu novo bot no Telegram (procure pelo username que você criou).

Abra o navegador e acesse este link (trocando <SEU_TOKEN> pelo token que o BotFather te deu):
https://api.telegram.org/bot<SEU_TOKEN>/getUpdates

Procure no texto que aparecer a parte "chat":{"id":123456789,...}. Esse número 123456789 é o seu Chat ID.
Anote esse número!

Passo 3.3 — Colocar no .env
Abra o arquivo .env:

bash
open -e .env
Adicione no final:

env
TELEGRAM_BOT_TOKEN=seu_token_aqui
TELEGRAM_CHAT_ID=seu_chat_id_aqui
